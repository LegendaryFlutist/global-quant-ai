# 入场质量与波动风控研究 v1

实现位于 `quant_lab/risk/`；版本化默认值在 `config/risk.json`。`quant_lab/services/risk_research.py` 恢复本机冻结GRU权重，沿用训练期标准化，绝不重新拟合。Web仅展示只读产物和假设仓位预算，无订单能力。

## 评分与预算

评分总计100：GRU方向分类支持50、大周期顺势25、已确认道氏123状态10、波浪方向10、反转形态5。分类支持未做获利概率校准。模型方向必须优于中性类别、分类支持至少0.45、大周期方向一致、已确认结构不能反向，且过去完整7天波幅在2%～50%。质量不足55分禁止新仓。

每次预算同时受四个约束：止损与双边成本预算、日波动预算、保证金上限、名义敞口上限。默认单笔估计风险不超过账户1%、保证金不超过20%、名义敞口不超过150%；杠杆上限10倍，试算可设置1～20倍。实际杠杆取波动上限、止损安全余量和用户上限中的较低整数。波动高时降低杠杆/敞口；账户回撤8%暂停新仓，并在接近该值时逐渐降低新仓预算。

杠杆、保证金比例与名义敞口是不同概念：名义敞口=杠杆×保证金。提高杠杆上限不保证分配更多敞口，更不保证更高收益。止损预算不是最大损失承诺。

研究按逐仓计算，维持保证金固定1%是假设，未获得用户实际杠杆/名义档位。Binance按标记价格检查强平，实际维持保证金随档位变化：[强平说明](https://www.binance.com/en/support/faq/detail/360033525271)、[杠杆与保证金说明](https://www.binance.com/en/support/faq/detail/360033162192)。禁止把该试算称为交易所核验的安全杠杆。

## 仅减仓规则

每项只触发一次，优先处理风险恶化：波动率达入场1.75倍减剩余50%；质量分下降20分减剩余50%；历史已观察峰值至少2R且回撤1R减剩余50%。随后按1R、2R各减初始仓位25%；价格直接跳到2R合并两档。R为入场价到初始止损距离。分批盈利后仅收紧止损，计入已知成本缓冲，但不声称保证盈亏平衡。风险减仓允许早于24小时；硬止损和标记价格强平优先，21天仍为最长持仓，数据截止会强制平仓。

决策只用此前已收盘评分/波动率与当前可观察开盘。历史峰值在该根完全收盘后才可用于下一开盘。不得使用当前根未来高低点决定开盘操作。所有成本、资金费、部分退出和持仓时长保存在产物中。

## 可复现运行

```bash
bash scripts/container.sh start
docker compose --env-file /dev/null -p quant-lab -f compose.yaml exec -T lab \
  python -m quant_lab.services.risk_research --timeframe 1h
bash scripts/platform.sh up
```

只访问四个白名单标的的本机冻结权重和真实数据，缺文件明确失败；GitHub新克隆没有这些私人研究产物。周期可选15m/30m/1h/2h/4h，上级为四倍。默认输出 `runs/risk_latest/report.json`，原子更新latest并保留时间戳归档；旧冻结批次不修改。每个结果包含模型/数据哈希、训练标签结束、验证区间、评分、三组曲线、交易和事件；总产物包含代码哈希与完整风险策略。无重训，无SMTP。

对照固定5倍/10%保证金、动态仓位、动态仓位加风险减仓，全部使用相同GRU候选、费用/滑点、延迟与退出模式；动态预算的评分/回撤拦截可能改变实际开仓时刻或次数。只复用原第3验证窗，原始行情在留出边界之前切断，保留留出不参与运算。该验证窗已被使用，结果仅为探索，不构成独立样本外证明，不自动晋升模型。

Web导航“评分与仓位风控”显示该历史结果。评分时间是验证窗末尾，明确不可作为当前交易信号；预算试算不会修改已显示曲线或默认策略。实时评分、Web多周期切换/运行、模型晋升、组合回测、持久模拟账户仍待开发。
